# True Light Church in Seattle

Website for True Light Church in Seattle, built as a pnpm monorepo.

## Apps

| App | Description |
| :-- | :---------- |
| `apps/web` | Astro frontend — public-facing website |
| `apps/studio` | Sanity Studio — content management |

## Development

```sh
pnpm install
pnpm dev:web      # http://localhost:4321
pnpm dev:studio   # http://localhost:3333
```

## Build

```sh
pnpm build
```
